### Astrbot_Plugin_QQ_Group_Manage
### 一款 QQ 群管家插件，支持自动同意加群、LLM 智能迎新送辞、以及机器人进群邀请的管理员审核。

***
> [!note]
> 本插件编写环境的AstrBot版本为v4.20.0，建议 AstrBot 版本 >= v4.20.0\
> 本插件完完全全依靠ai编写，如有问题还请多多包涵

### 兼容性说明

本插件基于 AstrBot 制作，当前使用 NapCat 的 OneBot 11 接口进行开发和验证。
其他完整支持本插件所使用的 OneBot 11 事件和 API 的实现理论上也可以使用，
但不同实现可能存在字段或行为差异，因此暂不保证完全兼容。
本插件不保证兼容 OneBot 12。

### 命令
- `/bot_join <审核ID> <同意/拒绝>`
  - **管理员专属指令**：用于处理机器人被邀请加入新群的请求。
  - 示例: `/bot_join 123456 同意`
  - 示例: `/bot_join 654321 拒绝`

### 功能特性

- **智能迎新与送辞**：群成员变动时，自动调用大语言模型（LLM）生成热情或惋惜的专属文案。
- **深度人格融合**：完美兼容 AstrBot 的人格设定系统，迎新/送辞/安抚消息均可指定特定人格的语气进行回复。
- **进群邀请审核**：当路人邀请机器人加入新群时，机器人会先安抚邀请者，并向管理员发送审核通知。支持 24 小时超时自动拒绝。
- **自动同意加群**：可配置自动同意路人加入机器人所在群聊的申请。
- **黑白名单群管**：支持配置群号黑白名单，精准控制插件在哪些群聊中生效。
- **多模型轮询兜底**：支持在 WebUI 中配置多个备用大模型。当主模型因网络波动或无余额报错时，自动无缝切换备用模型重试。
- **静态文本兜底**：当所有大模型均不可用时，自动发送预设的静态兜底文本，确保迎新、送辞、审核流程永不中断。
- **群成员名片缓存**：默认关闭。开启后，插件首次收到群事件时会自动同步管理群的成员名片，并按配置间隔定时刷新；送辞优先使用缓存群名片，缓存不可用时使用 QQ 昵称，最后回退到 QQ 号。

### 使用工作流示例

#### 场景一：迎新与送辞
1. 在 WebUI 中选择一个傲娇人格，并开启迎新功能。
2. 新人加群。
3. 机器人自动在群内发送：`@新人 哼，既然你诚心诚意地加群了，那我就勉为其难地欢迎你一下吧！记得看群规哦！`

群成员名片缓存默认关闭。开启后，送辞会将缓存到的群名片和 QQ 号提供给 LLM，
由 LLM 自行生成合适的告别文本，不会由插件强制追加固定句式。

#### 场景二：邀请机器人进群审核
1. 路人 A 邀请机器人加入群聊 `999999`。
2. 机器人私聊路人 A：`我已经通知我的管理员啦，请耐心等待管理员审核哦~`
3. 管理员的 QQ 收到私聊通知：
   ```text
   收到新的进群邀请！
   群号：999999
   邀请人：12345678
   审核ID：884823
   请回复指令进行审核：
   /bot_join 884823 同意
4. 管理员发送 `/bot_join 884823` 同意。
5. 机器人自动同意加群，并私聊通知路人 A：`您邀请我加入群聊 999999 的请求已被管理员【同意】。`
